# 🧾 Web Based Point of Sale (POS) System

A responsive Web-Based Point of Sale (POS) System developed using HTML, CSS, and JavaScript.
This project simulates a real-world retail POS system that allows users to manage products, customers, and orders while calculating totals and displaying order summaries.

#### The system is designed with a modern responsive UI that works smoothly on desktop, tablet, and mobile devices.

## 🚀 Features

- 🛒 Add products to cart

- 💰 Automatic total price calculation

- 📋 Order summary display

- 📦 Product management 

- 🧾 Order management

- 📱 Fully responsive design

- ⚡ Fast and interactive UI

### 🏪 POS Scenario

#### This POS system is designed for a Burger Shop (GrillMaster POS).

## Users can:

- Select burgers, fries, and drinks

- Add items to the cart

- Calculate the total bill

- Manage products, and orders

## 🛠️ Technologies Used

- HTML5 – Structure of the application

- CSS3 – Styling and responsive design

- JavaScript (ES6) – Application logic and interactivity

- Git & GitHub – Version control

- GitHub Pages – Deployment
